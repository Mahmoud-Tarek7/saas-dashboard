# نظام إدارة حلقات التحفيظ - تشغيل المشروع

## الخطوات

### 1. فك ضغط المشروع وادخل عليه
```
cd quran-center-app
```

### 2. ثبّت المكتبات
```
npm install
```

### 3. شغّل المشروع محليًا
```
npm run dev
```

هيفتح على: http://localhost:3000

### 4. أنشئ أول مستخدم إداري (Admin)
النظام مفيهوش شاشة "تسجيل جديد" عمدًا (عشان المدير بس يقدر يضيف إداريين). عشان تعمل أول حساب:

1. روح للوحة تحكم Supabase → **Authentication** → **Users**
2. دوس **Add user** → **Create new user**
3. حط إيميل وباسورد (احفظهم كويس)
4. سيبه من غير "Auto Confirm" متعطلة (يعني خليها مفعّلة/Confirm email تلقائي)

بعد كده روح `http://localhost:3000/login` وسجل دخول بنفس البيانات.

## هيكل المشروع

```
app/
  login/          → شاشة تسجيل الدخول
  page.js         → الصفحة الرئيسية (ليستة الحلقات)
  halaqa/[id]/attendance/  → تسجيل حضور حلقة معينة
  students/       → إدارة الطلاب
  subscriptions/  → متابعة الاشتراكات الشهرية
components/
  NavBar.js       → شريط التنقل العلوي
  AuthGuard.js    → حماية الصفحات (يتأكد إن المستخدم مسجل دخول)
lib/
  supabase.js     → إعداد الاتصال بـ Supabase
```

## ملاحظات مهمة

- **.env.local** فيه مفاتيح الاتصال بمشروعك على Supabase بالفعل، مفيش حاجة تعملها هنا.
- لو عايز تنشر المشروع على الإنترنت (مش بس محليًا)، هنستخدم Vercel، قولّي لما توصل للمرحلة دي.
- الحضور بيتسجل بشكل افتراضي "حاضر" لكل الطلاب، والإداري بس يدوس على اللي غايب يغيّر حالته.

## المشاكل الشائعة

**لو npm install وقف بخطأ:** تأكد إن عندك اتصال إنترنت شغال والـ Node version بتاعك 18 أو أحدث (عندك 22.14.0 فمفيش مشكلة).

**لو الصفحة فاضية بعد تسجيل الدخول:** تأكد إنك شغلت ملف `database-setup.sql` في SQL Editor على Supabase، وإن الجداول والبيانات التجريبية اتعملت (روح Table Editor وشوف جدول halaqat فيه 5 صفوف).
